# 阶段四：商品上架与优化

## 目标
上架即优化。让每个商品从标题、主图到详情页都具备获取搜索流量和转化的能力。

## 1. 标题公式（30 字 / 60 字符）

```
营销词 + 类目核心词 + 属性词 + 长尾词 + 卖点词
```

示例（收纳盒）：
「大容量收纳盒桌面化妆品护肤品收纳架家用卧室塑料多功用整理盒」

### 组词规则
- 核心词放前 13 字（手机端仅显示前半段，权重最高）
- 避免堆砌：一个标题 1 个核心词 + 2-3 个长尾词
- 不用符号隔断（空格、斜杠会被降权），不用违禁极限词
- 每周根据生意参谋搜索词数据微调一次，替换零流量词

### 关键词来源
1. 生意参谋 → 市场 → 搜索分析（输入核心词，取搜索人气高、在线商品数少的词）
2. 淘宝搜索下拉框联想词
3. 竞品标题高频词提取（用 scripts/title_optimizer.py 分析）

## 2. 主图五张规划

| 图位 | 内容要求 |
|------|---------|
| 第 1 张 | 卖点+促销信息，与白底竞品形成差异（禁止牛皮癣过多） |
| 第 2 张 | 产品全貌 + 核心参数 |
| 第 3 张 | 细节/材质特写 |
| 第 4 张 | 使用场景图 |
| 第 5 张 | 白底图（部分活动报名必须） |

- 尺寸 800×800px 以上，主图视频 9-60 秒可显著提升转化
- 主图点击率（CTR）是搜索流量的第一权重，用直通车测图，CTR ≥ 行业均值 1.2 倍再定稿

## 3. 详情页转化逻辑（FABE 法则）

1. **Attention**：首屏 3 秒抓住痛点（场景图/对比图/痛点文案）
2. **Feature**：产品亮点逐条展示（图文结合，一屏一卖点）
3. **Advantage**：与竞品/传统方案对比（表格/实测数据）
4. **Benefit**：用户能得到什么（前后对比、买家秀）
5. **Evidence**：资质证书、检测报告、买家好评截图
6. **Action**：促销信息 + 常见问题 FAQ + 尺码/规格对照表

移动端优化：竖版排版、字号 ≥ 24px、单图高度 ≤ 1500px、前 3 屏决定去留。

## 4. SKU 与定价策略

- SKU 图必须清晰展示差异（颜色/尺寸/套装），最低价 SKU 不得与主图商品严重不符（防「低价引流」违规）
- 定价三法：
  - 成本加成：成本 ÷ (1 − 目标毛利率)，毛利率建议 ≥ 45%
  - 竞品锚定：比头部竞品低 5-10%，或同价多送赠品
  - 价格带卡位：选择竞品数量少的空白价格带
- 心理定价：39.9 / 59 / 89 优于整数
- 设置 SKU 阶梯：引流 SKU（低价）→ 主推 SKU → 利润 SKU（套装）

## 5. 上架时间与商品规划

- 商品结构：1-2 个引流款（低价冲量）+ 3-5 个利润款 + 若干常规款，总数 20-50 个为宜（C 店）
- 上架时间选类目流量高峰前 1-2 小时（生意参谋看类目时段分布）
- 7 天上下架权重：保证每天有商品临近下架，获得周期性流量

## 产出物
- 每个商品：优化标题 + 5 主图 + 详情页 + SKU 表 + 价格表
