# 阶段五：店铺装修

## 目标
搭建统一的视觉体系，让店铺首页成为「无声的销售员」，提升停留时长和转化率。

## 1. 装修优先级（流量大头在移动端）

1. 手机端详情页（承接 90%+ 流量）＞
2. 主图与主图视频 ＞
3. 手机端店铺首页 ＞
4. PC 端（可后期补做）

## 2. 首页结构（从上到下）

| 模块 | 内容 | 目的 |
|------|------|------|
| 店招 | logo + 一句定位文案 + 关注按钮 | 品牌记忆 |
| 焦点图 | 1-3 张活动/主推海报 | 引导点击 |
| 优惠券 | 满减/折扣券领取 | 促单 |
| 商品分类导航 | 按场景/人群/价格分类 | 降低寻找成本 |
| 主推爆款区 | 引流款 + 利润款组合陈列 | 走量 |
| 内容区 | 买家秀/短视频/品牌故事 | 信任背书 |
| 底部 | 售后保障图标（7天退换/运费险/正品） | 打消顾虑 |

## 3. 视觉统一三要素

- 主色：1 个主色 + 1 个辅色（沿用行业信任色：家居用暖色、数码用黑蓝）
- 字体：标题 1 种 + 正文 1 种，不超 2 种
- 摄影风格：同一批产品用统一背景、光线、角度拍摄

## 4. 工具与资源

- 官方工具：卖家中心 → 店铺装修（千牛 PC 端）；手机端用「无线装修」
- 模板市场：装修市场有付费模板（50-300 元/月），新手可先用免费模板
- 设计工具：稿定设计、创客贴、Canva（有淘宝尺寸模板）
- 图片要求：首页海报宽度 750px（手机端），单张大小 ≤ 3MB

## 5. 快速检查清单

- [ ] 从搜索结果点进店铺，3 秒内能看懂卖什么
- [ ] 首页所有图片清晰、无变形、无过期活动信息
- [ ] 优惠券金额真实有效
- [ ] 分类导航点击后商品排列合理
- [ ] 全店视觉风格统一，无明显「拼凑感」

## 常见坑
- 过度装修：首页炫酷但加载慢，跳出率反升
- 信息过期：活动结束后海报未撤，用户进店看到过期价格引发投诉
- 忽视微详情：主图视频缺失，白白损失转化利器
