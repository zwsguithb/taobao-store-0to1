# 阶段二：店铺注册与搭建

## 目标
完成店铺类型选择、注册认证和基础设置，让店铺具备营业条件。

## 1. 店铺类型对比

| 类型 | 门槛 | 保证金 | 适合人群 |
|------|------|--------|---------|
| 淘宝个人店（C店） | 身份证实名 | 1000 元（可选 30 元/年保险替代） | 新手首选，零成本试错 |
| 淘宝企业店 | 营业执照 | 1000 元起 | 有公司主体，权重略高 |
| 天猫旗舰店 | 商标 + 公司 + 入驻审核 | 5-15 万保证金 + 年费 | 有品牌和资金实力 |

**新手建议：先开淘宝 C 店验证模式，跑通后再升级。**

## 2. 注册流程（淘宝 C 店）

1. 准备材料：身份证正反面照片、手机号、支付宝账号（实名一致）、银行卡
2. 下载千牛 APP 或访问 taobao.com → 免费开店
3. 选择「个人店铺」→ 填写主体信息 → 人脸识别认证
4. 绑定支付宝完成实名核验
5. 缴纳保证金（发布商品前必须）：卖家中心 → 消费者保障 → 缴纳
6. 完成开店考试（部分类目需要）

- [ ] 支付方式、发票设置
- [ ] 子账号与权限（如有多人运营）

## 4. 新店扶持期规则（重点）

- 开店前 3 个月为新店扶持期，有流量倾斜，**务必在此期间完成上架和破零**
- 新店第一单（破零）至关重要：可通过亲友、老客、低价引流款完成
- 一个身份证只能开一个个人店；重复开店会被限流

## 5. 违规红线（开店必读）

- **虚假交易（刷单）**：稽查严格，轻则清洗销量删除评价，重则封店
- **售假**：直接扣 48 分封店，永久不得再开店
- **极限词**：详情页和标题出现「最」「第一」「国家级」等违禁词会被投诉
- **盗图**：使用他人图片会被删商品扣分，主图详情页必须原创或授权
