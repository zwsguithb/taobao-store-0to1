# 阶段一：市场调研与选品定位

## 目标
在开店前完成赛道选择、竞品调研和利润测算，确定「卖什么、卖给谁、凭什么赢」。

## 1. 赛道评估四维度

| 维度 | 评估要点 | 判断标准 |
|------|---------|---------|
| 市场容量 | 类目搜索人气、成交金额 | 生意参谋-市场-搜索分析，月搜索人气 > 1万 |
| 竞争强度 | 在售商品数、头部集中度 | TOP10 销量占类目比 < 50% 为相对蓝海 |
| 增长趋势 | 同比/环比增长 | 类目销售额连续 3 个月正增长 |
| 进入门槛 | 资质要求、资金门槛 | 避开需特殊资质且无法获取的类目 |

## 2. 选品五步法

1. **泛选**：从兴趣、经验、产业带、热点四来源列出 20 个候选类目
2. **初筛**：用四维度评分卡（各 1-5 分）淘汰至 5 个以内
3. **深研**：对候选类目做竞品拆解（用 scripts/competitor_analysis.py）
4. **测算**：毛利 = 售价 −（货款 + 快递 + 包装 + 推广 + 平台扣点），毛利 ≥ 40% 且单笔净利 ≥ 10 元
5. **验证**：1688 找 3 家以上供应商比价打样，确认货源稳定后再注册店铺

## 3. 新手友好与新手慎入类目

- **新手友好**：家居百货、收纳用品、汽车周边、宠物用品、本地特色食品（低客单、低退货、非标品空间大）
- **新手慎入**：女装女鞋（高退货率）、3C 数码（价格透明）、美妆（资质+备案）、大牌食品（授权门槛）

## 4. 定位三问（必答）

1. 我的目标人群是谁？（年龄/性别/消费力/使用场景，越具体越好）
2. 我的差异化是什么？（价格 / 设计 / 服务 / 组合 / 内容）
3. 用户为什么放弃竞品选我？（一句话能说清，否则重新定位）

## 5. 产出物

- 《选品评估表》：候选类目 × 四维度评分 + 结论
- 《竞品拆解表》：TOP5 竞品的价格、销量、卖点、差评关键词
- 《利润测算表》：成本结构 + 盈亏平衡点（推广费占比）

## 常见坑
- 只看别人爆款就跟卖，不核实竞争已白热化
- 忽略退货率：服饰类退货 30%+ 会直接吞噬利润
- 先开店再选品，白白消耗新店扶持期流量
