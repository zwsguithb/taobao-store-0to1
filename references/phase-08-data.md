# 阶段八：运营与数据分析

## 目标
建立以数据为驱动的日常运营节奏，用生意参谋定位问题、迭代优化。

## 1. 核心指标体系（每日必看）

| 指标 | 含义 | 健康值 | 位置 |
|------|------|--------|------|
| 访客数 (UV) | 店铺流量 | 环比上升 | 生意参谋-流量 |
| 转化率 | 成交买家/访客 | ≥ 类目均值 | 生意参谋-交易 |
| 客单价 | 成交额/买家数 | 通过搭配提升 | 生意参谋-交易 |
| UV 价值 | 成交额/访客 | 越高排名越稳 | 计算 |
| 收藏加购率 | (收藏+加购)/访客 | ≥ 8% | 商品效果 |
| 退款率 | 退款订单/总订单 | ≤ 类目均值 | 交易 |
| DSR 评分 | 描述/服务/物流 | 全绿 ≥ 4.8 | 首页 |

## 2. 诊断三步法（流量掉了怎么办）

1. **定位流量渠道**：生意参谋-流量来源，看是搜索、推荐还是付费下滑
2. **定位具体商品**：商品效果排行，找访客下滑 TOP 商品
3. **定位环节**：
   - 展示量降 → 关键词排名变化或竞品打压
   - 点击率降 → 主图/价格竞争力问题
   - 转化率降 → 详情页、评价、活动结束

## 3. 日常运营节奏表

| 频率 | 动作 |
|------|------|
| 每日 | 看核心指标、处理客服售后、检查库存与物流异常、直通车微调 |
| 每周 | 标题关键词微调、评价关键词复盘、活动报名筛查、竞品动态跟踪 |
| 每月 | 全店商品动销复盘（清滞销）、利润核算、推广 ROI 复盘、下月计划 |

## 4. 商品生命周期运营

- **导入期（0-30 天）**：破零 + 累积基础销量评价 + 直通车测款
- **成长期**：加大推广、申报活动、冲类目排名
- **成熟期**：稳排名 + 拓展关联销售 + 提升 UV 价值
- **衰退期**：减少投入、清库存、用新品接力流量

## 5. 利润核算模型（每月必做）

```
净利润 = 销售额 − 货款成本 − 快递包装 − 推广费 − 平台扣点（约 5%）− 退款损耗 − 其他
```

用 scripts/dashboard_generator.py 生成月度经营看板，跟踪：
- 毛利率走势、推广费占比（健康 ≤ 30%）、净利率（健康 ≥ 10%）
- 单品盈利排行（往往 20% 商品贡献 80% 利润，聚焦资源）

## 常见坑
- 只盯销售额不看利润：大促冲量后一算亏钱
- 数据工具只用免费版基础功能：生意参谋标准版对月销过万店铺值得投入
- 缺乏对照：不看类目均值，无法判断自身好坏
