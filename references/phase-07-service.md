# 阶段七：客服体系

## 目标
用标准化话术和高响应速度提升询单转化率，把售后变成复购契机。

## 1. 基础设置

- 工具：千牛（PC + 手机），开启离线自动回复
- 响应时效：首次响应 ≤ 30 秒（客服 KPI 第一指标）
- 挂牌时间：9:00-23:00（买家活跃时段全覆盖），人手不足时至少 12 小时在线
- 子账号分工：售前/售后分开，权限最小化

## 2. 售前转化话术框架（问询 → 成交）

1. **欢迎语**（3 秒内）：您好～欢迎光临 XX 专营店，看中可以拍下哦，今天下单送 XX（利益点）
2. **需求确认**：请问是自己用还是送人呢？/ 需要什么尺寸、颜色？
3. **产品推荐**：根据需求推 1-2 个 SKU，说清差异，不罗列全部
4. **异议处理**（价格贵）：「咱家用的是 XX 材质/工艺，耐用度是普通款的 X 倍，算下来每天才几毛钱」
5. **催付**（拍下未付 15 分钟后）：亲，您拍下的宝贝库存紧张啦，现在付款今天就能发出哦
6. **下单关怀**：感谢信任！我们会 24 小时内发出，发货后第一时间通知您

## 3. 售后处理 SOP

| 场景 | 处理步骤 | 时限 |
|------|---------|------|
| 物流未更新 | 查单号 → 联系快递 → 主动告知买家进展 | 24h 内响应 |
| 质量问题 | 致歉 → 让买家拍照核实 → 补发或部分退款 | 48h 内解决 |
| 退货退款 | 同意申请 → 给退货地址 → 收货验货退款 | ≤ 处理时限 |
| 差评 | 致歉电话/私信 → 了解原因 → 补救（退款/换货/补偿）→ 请求修改 | 24h 内联系 |
| 纠纷投诉 | 优先协商；小金额建议让步，避免小二介入影响店铺分 |

黄金法则：**售前不过度承诺，售后不推诿扯皮。**

## 4. 评价管理

- 引导好评：包裹卡 + 客服跟进（「晒图返 3 元」注意平台对返现管控，建议用「晒图送小礼品/优惠券」）
- 中差评回复模板：先致歉认领问题 → 说明解决方案 → 体现店铺负责态度（回复是给后续买家看的）
- 评价关键词每月复盘一次，高频差评点反哺选品和详情页改进

## 5. 客服数据指标

- 询单转化率：≥ 60% 及格（用生意参谋-服务看板监控）
- 平均响应时间：≤ 30 秒
- 客服满意度：≥ 95%
- 纠纷退款率：≤ 0.1%
