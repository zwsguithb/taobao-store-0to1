# 淘宝开店启动清单（0-1 全流程勾选表）

> 用法：按阶段推进，每完成一项打勾。全部完成即达成月销破千的 0-1 阶段。

## 阶段一：市场调研与选品定位（第 1-2 周）
- [ ] 列出 20 个候选类目（兴趣/经验/产业带/热点）
- [ ] 用四维度评分卡筛选至 5 个以内（scripts/product_research.py）
- [ ] 拆解 TOP5 竞品价格、销量、卖点、差评（scripts/competitor_analysis.py）
- [ ] 完成利润测算：毛利率 ≥ 40%、单笔净利 ≥ 10 元
- [ ] 1688 找到 3 家供应商比价，并购买样品验证
- [ ] 明确定位三问：目标人群、差异化、一句话卖点

## 阶段二：店铺注册与搭建（第 2 周）
- [ ] 准备身份证、手机号、实名支付宝、银行卡
- [ ] 注册淘宝个人店并通过人脸认证
- [ ] 缴纳保证金（1000 元或 30 元/年保险替代）
- [ ] 完成店铺基础设置（名称/logo/简介/地址/运费模板/客服时间）
- [ ] 熟悉千牛工作台基本操作

## 阶段三：货源与供应链（第 2-3 周）
- [ ] 确定合作供应商（样品合格 + 价格最优 + 发货时效达标）
- [ ] 确定起步模式（一件代发 / 小批量囤货）
- [ ] 约定售后与次品赔付条款
- [ ] 建立备用供应商清单（至少 1 家）

## 阶段四：商品上架与优化（第 3-4 周）
- [ ] 拍摄产品图（5 主图规划 + 白底图 + 主图视频）
- [ ] 制作详情页（FABE 结构，移动端竖版）
- [ ] 优化标题（scripts/title_optimizer.py generate/check）
- [ ] 设置 SKU 与阶梯定价（引流款/主推款/利润款）
- [ ] 上架 20-50 个商品，上架时间选类目流量高峰前 1-2 小时

## 阶段五：店铺装修（第 4 周）
- [ ] 手机端首页装修（店招/焦点图/优惠券/分类导航/爆款区）
- [ ] 视觉统一（主色 + 辅色 + 字体不超 2 种）
- [ ] 装修检查：3 秒看懂卖什么、图片无过期信息

## 阶段六：营销推广（第 4-8 周）
- [ ] 新品破零（真实订单，严禁刷单）
- [ ] 开通直通车，日预算 100-300 元测款测图
- [ ] 报名淘金币/天天特卖等低门槛活动
- [ ] 开通逛逛内容发布（每周 3-5 条）
- [ ] 设置店铺优惠券与满减

## 阶段七：客服体系（第 4 周起持续）
- [ ] 配置欢迎语/自动回复/离线回复
- [ ] 编写售前话术手册（欢迎-需求-推荐-异议-催付）
- [ ] 建立售后 SOP（物流/质量/退货/差评处理时限）
- [ ] 首次响应 ≤ 30 秒，询单转化率 ≥ 60%

## 阶段八：运营与数据分析（每周固定动作）
- [ ] 每日看板：UV、转化率、客单价、退款率
- [ ] 每周：关键词微调、评价复盘、活动筛查
- [ ] 每月：利润核算 + 经营看板（scripts/dashboard_generator.py）
- [ ] 每月：滞销清理（30 天零动销打折清仓）

## 阶段九：物流与发货（第 4 周起持续）
- [ ] 申请电子面单，谈妥 1 主 1 备快递合作
- [ ] 发货 SOP：16 点前订单当天发，48 小时时效红线
- [ ] 加入 7 天无理由 + 运费险
- [ ] 定制包装 + 包裹卡（合规引导关注店铺）

## 阶段十：规模化增长（月净利稳定 ≥ 1 万后）
- [ ] 爆款延伸 + 关联搭配，构建商品梯队
- [ ] 注册商标，筹备品牌化
- [ ] 拓展第二渠道（拼多多/抖音）
- [ ] 沉淀运营 SOP，第一个员工（客服或打包）
